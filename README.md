## ✨ What's inside

🪟 **Profile revision first** — revision number and date printed in the header before you touch a menu. If a page can't tell you the revision, it's a re-post, not a source.

🧮 **SHA-256 line** — hash published next to the revision so the downloaded pack can be verified with `certutil -hashfile`. Mismatch means re-download, not "probably fine".

🖥️ **Hz unlock is a handshake, not a switch** — the console only offers 120 Hz when the cable, the port and the TV all agree. The ladder checks all three before it asks for the mode.

🧱 **Platform split, kept apart** — PS5, Series X and Series S get separate paths. Series S has no disc drive and a lower render target; a Series X ladder dropped on it is half wrong.

📁 **Menu paths on the table** — every step is a literal path: `Settings → Screen and Video → Video Output`, not "turn on performance". No guessing which submenu.

⚙️ **No hidden steps** — the whole ladder is written out, in order, with the read-back that proves each step landed, and nothing that requires a PC.

🔌 **TV side included** — game mode, ALLM, motion interpolation off, HDMI port label set to "PC/enhanced". Half the console ladders fail on the TV, not the console.

💾 **Snapshot before you start** — a printable card with your original output mode, HDR state and VRR state, so every step has a reverse.

♻️ **Rollback line** — the previous revision kept, plus the exact reverse path per step. A profile that stutters on your set should have a way back.
